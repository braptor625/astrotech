# Steam achievements

Create these in Steamworks under **App Admin → Stats & Achievements → Achievements**. The API Name must match exactly.

| API Name | Display name | Description |
|---|---|---|
| `ACH_FIRST_LAUNCH` | Liftoff | Launch your first mission. |
| `ACH_FIRST_SALE` | Open for Business | Sell your first cargo. |
| `ACH_SURVEY` | Know Your Rock | Survey an asteroid. |
| `ACH_FIRST_LOSS` | Acceptable Losses | Lose a ship. |
| `ACH_MISSIONS_100` | Regular Service | Complete 100 missions in total. |
| `ACH_MISSIONS_1K` | Launch Cadence | Complete 1,000 missions in total. |
| `ACH_MISSIONS_10K` | Industrial Scale | Complete 10,000 missions in total. |
| `ACH_FLEET_10` | Fleet Owner | Own 10 ships at once. |
| `ACH_PADS_6` | Spaceport | Own 6 launch pads. |
| `ACH_PILOT_10` | Ace | Train a pilot to level 10. |
| `ACH_PILOT_20` | Living Legend | Train a pilot to level 20. |
| `ACH_DEATHS_10` | Attrition | Lose 10 pilots. The memorial wall has room. |
| `ACH_MILLION` | Seven Figures | Earn $1,000,000 in a single run. |
| `ACH_BILLION` | Ten Figures | Earn $1,000,000,000 in a single run. |
| `ACH_IPO` | Going Public | Research Incorporation. |
| `ACH_QUARTER_5` | Beat and Raise | Beat quarterly guidance 5 times in a row. |
| `ACH_CRASH` | Flooding the Market | Crash an ore price below 10% of normal. |
| `ACH_CONTRACTS_25` | Preferred Vendor | Deliver 25 contracts in total. |
| `ACH_REP_MAX` | Household Name | Reach the highest reputation level. |
